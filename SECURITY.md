# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| `0.1.x` | Yes |

Security fixes land on `main` and ship in the next patch tag.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Use GitHub private vulnerability reporting:

https://github.com/AlexGalhardo/studio.vukem.dev/security/advisories/new

Include what you can do, the version or commit, and the smallest steps that show the problem. You will get an acknowledgement within 7 days, and a plan or a reason the report is out of scope within 30 days.

A report about a skill kit's example media, or about a third-party product named in `docs/recommend-tools.md`, is out of scope unless Studio's own code calls that product in an unsafe way.
