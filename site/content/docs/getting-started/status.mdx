Studio is at `v0.1.0` of the repository, not of a video product. The first slice is the documentation site, the research, the unpacked skills, and the release tooling.

## In this repository

- Documentation site with the same docs shell as vukem.dev
- Research notes in `docs/web-research.md`
- Skill kits under `.agents/skills/`
- GitHub Actions for markdown, the site, OpenSSF Scorecard, pull request titles, and version tags
- Docker image for the documentation site
- Roadmap with audit checks

## Not in this repository yet

- The Vukem dashboard application
- Google sign-in
- A render queue
- An end-to-end brief that produces an MP4

Those items are phases in `ROADMAP.md`. A box is `[x]` when the audit checks under it pass, `[/]` when the work is only partly true, and `[ ]` when it has not started.
