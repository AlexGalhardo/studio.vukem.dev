title: Quickstart
description: Run the Studio app locally and render a first video from a brief.

Studio is a Go application built on [Vukem](https://vukem.dev/docs) with an Inertia and React front end. It needs Go, Bun, and FFmpeg.

## Requirements

| Tool | Why |
| --- | --- |
| Go 1.27 | Builds the app |
| Bun 1.4.4 | Builds the front end assets |
| FFmpeg and `ffprobe` on `PATH` | Renders and checks the MP4 |
| DejaVu Sans font | libass draws the burned-in captions with it |

## Run it

```bash
cp .env.example .env
bun install
bun run build
go run ./cmd/app migrate
go run ./cmd/app
```

Open `http://localhost:3000`. A signed-out visitor lands on `/login`.

Set `SOCIAL_GOOGLE_CLIENT_ID` and `SOCIAL_GOOGLE_CLIENT_SECRET` in `.env` for Google sign-in. Set `ANTHROPIC_API_KEY` (or `STUDIO_MODEL` with `OPENAI_API_KEY`) for a hosted model. The [configuration](/docs/configuration) page lists every variable.

## Make a video

1. Sign in, open **Jobs**, create a job, and fill the brief.
2. Submit. The job page shows `queued`, `rendering`, and then `ready`.
3. Download the MP4, the captions, and build a publish pack.

With no key and no `STUDIO_MODEL` the app uses the deterministic local planner, so a silent video renders without a network. A hosted model set without its key fails the job with a message that names the missing variable.

## Run the checks

```bash
gofmt -l .
go vet ./...
go test ./...
bun run typecheck
```

One test spends money and is off by default: `STUDIO_TEST_REAL_MODEL=1` makes one paid Claude call, then renders and checks the file. It needs `ANTHROPIC_API_KEY`.
