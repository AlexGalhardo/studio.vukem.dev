---
title: Configuration
description: Every environment variable the Studio app reads.
---

The app reads its configuration from the environment and an optional `.env` file. Nothing here is committed with a value.

## Framework

| Variable | Purpose |
| --- | --- |
| `APP_ENV` | `development`, `test`, or `production` |
| `APP_KEY` | Encrypts sessions and tokens. Required in production |
| `APP_URL` | Public origin. `https://app.studio.vukem.dev` in production. The Google callback is built from it |
| `DATABASE_URL` | SQLite file or PostgreSQL URL |
| `QUEUE_CONNECTION` | `database` in production so `serve` runs the render worker. `sync` renders inside the request |
| `PORT`, `HOST` | Listen address |

## Sign-in

| Variable | Purpose |
| --- | --- |
| `SOCIAL_GOOGLE_CLIENT_ID` | Google OAuth client id |
| `SOCIAL_GOOGLE_CLIENT_SECRET` | Google OAuth client secret |

## Models

| Variable | Default | Purpose |
| --- | --- | --- |
| `STUDIO_MODEL` | see below | `claude-sonnet-5-5`, `claude-opus-5-5`, an OpenAI model id, or `local-planner` |
| `ANTHROPIC_API_KEY` | none | Claude models |
| `OPENAI_API_KEY` | none | OpenAI models. Any model id that does not start with `claude-` |
| `STUDIO_MAX_OUTPUT_TOKENS` | `4000` | Base output cap of one model call. 30 tokens per second of video are added |
| `STUDIO_MAX_JOB_COST_CENTS` | `100` | Worst-case cost cap per job in US cents, from a built-in price table. `0` means no cap |

With `STUDIO_MODEL` unset the app uses `claude-sonnet-5-5` when `ANTHROPIC_API_KEY` is set, and the deterministic local planner otherwise. A model set without its key fails each job with a message that names the missing variable.

## Limits

| Variable | Default | Purpose |
| --- | --- | --- |
| `STUDIO_MAX_JOBS_PER_DAY` | `20` | Jobs per user in any rolling 24 hours. `0` means unlimited |

## Rendering and storage

| Variable | Default | Purpose |
| --- | --- | --- |
| `STUDIO_STORAGE` | `storage/renders` | One folder per job: the MP4, captions, sidecar. Mount a volume here in production |
| `STUDIO_RENDERER` | `ffmpeg` | `ffmpeg`, `hyperframes`, or `remotion`. The last two need their CLIs on `PATH` |

FFmpeg and `ffprobe` must be on `PATH`. The `.agents/skills` tree is found from the working directory or the binary's directory.
