A brief becomes a job row. A queue worker plans, renders, and checks it.

## States

| Status | Meaning |
| --- | --- |
| `queued` | Stored with its compiled prompt, waiting for a worker |
| `rendering` | The model is writing the plan, then FFmpeg encodes and QA checks the file |
| `ready` | The MP4 passed QA and can be downloaded |
| `failed` | A readable reason is stored on the job |

A job row keeps the brief, the style, the model id, the prompt, the raw model reply, the parsed plan, the script, the sidecar with the renderer and FFmpeg versions, and the publish pack.

## Failures

A failure is a stored state, never a silent queue retry, because each model call costs money.

| Cause | What the job shows |
| --- | --- |
| Hosted model without its key | The variable to set, for example `ANTHROPIC_API_KEY` |
| Model error or timeout | The provider status, without the response body |
| Worst-case cost over the cap | Both amounts and the variable to change |
| Reply is not a scene plan | `the model output is not a scene plan`. The raw reply stays on the job |
| A must-keep fact missing from the script | The fact |
| Encoder crash, timeout, or failed QA | The encoder or QA message |

## Re-run

**Retry** renders a `ready` or `failed` job again. The previous ready file stays in place until the new file passes QA, so one job never owns two public files. A job may be rendered five times in total. Parallel retries queue it at most once, and a retry of a job that is queued or rendering answers `409`.

## Limits

| Limit | Default | Enforcement |
| --- | --- | --- |
| Renders per user in any rolling 24 hours | 20 (`STUDIO_MAX_JOBS_PER_DAY`, `0` is unlimited) | A new job and each retry take a slot, counted in the same transaction as the insert or requeue, behind a per-user lock. A refused retry takes none |
| Duration of one video | 5 to 300 seconds | Brief validation, on the server |
| Model output tokens per call | 4000 plus 30 per second of video (`STUDIO_MAX_OUTPUT_TOKENS` sets the base) | Sent to the provider |
| Worst-case cost per job | 100 cents (`STUDIO_MAX_JOB_COST_CENTS`) | Checked before the call |
| One encoder or probe process | 5 minutes | Killed at the deadline |
| One queued job | 10 minutes | Queue timeout |
| Plan size | At most the duration in seconds plus 10 shots (400 at most), 500 characters per caption | Plan validation |

## Endpoints

All routes need a signed-in user with a verified email. A job of another user answers `404`.

| Method and path | Purpose |
| --- | --- |
| `GET /jobs` | List your jobs |
| `GET /jobs/create` | The brief form |
| `POST /jobs` | Create a job. `201` with JSON, or a redirect for the web UI |
| `GET /jobs/{id}` | One job with its prompt and plan |
| `POST /jobs/{id}/retry` | Re-render. `409` when it is queued, rendering, or out of attempts |
| `GET /jobs/{id}/download` | The MP4. `404` until the job is ready |
| `GET /jobs/{id}/captions.srt` | The caption file |
| `POST /jobs/{id}/pack` | Build the publish pack for a platform |

Send `Accept: application/json` to get JSON instead of Inertia pages. An invalid brief answers `422` with a `{field: [messages]}` body, and a signed-out JSON request answers `401`.
